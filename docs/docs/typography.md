# Typography

## Typeface

**Primary font:** Plus Jakarta Sans  
Fallback: `ui-sans-serif`, `system-ui`, `sans-serif`

Use a single family for the initial product to keep the interface cohesive.

## Type scale

| Token | Size | Weight | Usage |
|---|---:|---:|---|
| `display` | 40px / 2.5rem | 700–800 | Hero headline |
| `h1` | 32px / 2rem | 700 | Page title |
| `h2` | 24px / 1.5rem | 700 | Section title |
| `h3` | 20px / 1.25rem | 600–700 | Card or subsection title |
| `body-lg` | 18px / 1.125rem | 400–500 | Intro copy |
| `body` | 16px / 1rem | 400 | Main content |
| `body-sm` | 14px / 0.875rem | 400 | Supporting content |
| `caption` | 12px / 0.75rem | 400–500 | Metadata |

## Usage

- Use bold headings, but avoid making every text element bold.
- Keep body text at 16px where possible.
- Use 1.4–1.6 line-height for body copy.
- Use captions for metadata, not essential instructions.
- Keep labels concise and friendly.
