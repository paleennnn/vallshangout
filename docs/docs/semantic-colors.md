# Semantic Colors

Semantic colors communicate meaning, not brand identity. Keep them consistent across pages.

| Token | HEX | Meaning | Example |
|---|---|---|---|
| `success` | `#15803D` | Successful action or positive status | Saved, confirmed |
| `success-bg` | `#F0FDF4` | Success background | Success alert |
| `warning` | `#B45309` | Caution or pending state | Pending review |
| `warning-bg` | `#FFFBEB` | Warning background | Warning alert |
| `danger` | `#B91C1C` | Error or destructive action | Delete, failed request |
| `danger-bg` | `#FEF2F2` | Error background | Error message |
| `info` | `#0369A1` | Informational state | Tips, general notice |
| `info-bg` | `#F0F9FF` | Informational background | Info alert |

## Rules

- Pair semantic color with text, icon, or status label.
- Do not use orange as a substitute for every status.
- Destructive actions should use danger styling and clear confirmation.
- Check foreground/background contrast for badges and alerts.
