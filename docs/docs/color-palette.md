# Color Palette

| Token | HEX | Role |
|---|---|---|
| `brand-orange` | `#F97316` | Main brand accent and primary CTA |
| `brand-orange-hover` | `#EA580C` | Hover/pressed emphasis |
| `warm-cream` | `#FFF7ED` | Warm page background |
| `surface` | `#FFFFFF` | Cards, panels, dialogs |
| `warm-charcoal` | `#292524` | Main text and dark surfaces |
| `muted-text` | `#78716C` | Secondary text |
| `border` | `#E7E5E4` | Neutral borders |

## Usage rules

- Use orange for primary actions, active navigation, and selected highlights.
- Use cream for page-level warmth, not for every card.
- Use white for content surfaces to keep cards legible.
- Use charcoal for primary text.
- Use neutral gray for secondary text and borders.
- Keep success, warning, danger, and info colors separate from brand orange.

## Contrast note

The orange `#F97316` is a brand accent. White text on this orange may not meet WCAG AA contrast for normal text. For small button labels, prefer a dark text color such as `#292524`, or use a darker orange token and verify contrast with a checker. Always test actual combinations before release.
