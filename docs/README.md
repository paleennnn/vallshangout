**Core palette:** Orange + warm cream + charcoal  
**Status:** Initial design-system draft

## Design principles

1. **Warm, not loud:** use orange for meaningful emphasis, not every surface.
2. **Content-led:** photos of places and hangout experiences should carry the visual story.
3. **Friendly and clear:** rounded components, comfortable spacing, readable type.
4. **Consistent semantics:** status colors keep the same meaning across the product.
5. **Accessible contrast:** verify text/background combinations before shipping.

## Suggested stack

- Next.js
- Tailwind CSS
- Plus Jakarta Sans
- CSS custom properties as the source of truth

> This is a starter system. Validate the palette against real screens, accessibility contrast, and the product's final feature set before treating it as production-final.
